# ⚡ QR Studio Pro | High-Performance Custom QR Code Generator

A modern, ultra-fast, feature-rich QR code generator web application built with React, Vite, and `qr-code-styling`.

## ✨ Features

- 🔗 **Multiple Data Formats**: URL/Link, Wi-Fi configuration, vCard (Contact details), Email templates, SMS/WhatsApp messages, and Plain Text.
- 🎨 **Deep Customization**:
  - Aesthetic Color Themes (Cyber Neon, Midnight Dark, Emerald Glow, Sunset Fusion, Royal Purple, Gold Luxury, Clean White).
  - Custom Foreground & Background colors with Linear Gradient support.
  - Transparent background support.
  - Dot patterns (Square, Dots, Rounded, Extra Smooth, Classy).
  - Corner Frame & Eyeball styling options.
- 🖼️ **Branding & Logo Overlays**: Add center logo icons (built-in SVG collection or upload custom PNG/SVG logo images).
- ⚡ **Real-Time 60FPS Live Preview**: Instant canvas rendering as you type.
- 📥 **Multi-Format HD Export**: Download in PNG, SVG (Vector), WEBP, or copy PNG directly to clipboard. Export resolutions up to 2400px (4K).
- 📦 **Batch QR Generator**: Generate QR codes in bulk from a list of links.
- 🔍 **Built-in QR Scanner**: Drag-and-drop or upload any QR image file to decode its text/URL.
- 📜 **Saved History**: Auto-saves generated QR codes to browser local storage.

## 🚀 Getting Started

### Installation

```bash
# Clone the repository
git clone https://github.com/himanshu180105/qr_code18.git

# Navigate to project folder
cd qr_code18

# Install dependencies
npm install
```

### Development Server

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build

```bash
npm run build
```
